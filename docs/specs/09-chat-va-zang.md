# 09 — Чат, паёмҳои овозӣ ва зангҳо

## Мақсад

Кормандон дар дохили сайт мисли WhatsApp/Telegram менависанд, паёми овозӣ ва видео-доира мефиристанд ва занги аудио/видео мезананд.
Нусхаи паём ба WhatsApp ё Telegram-и корманд ҳам меравад, ва ҷавоби ӯ аз он ҷо ба чати сайт бармегардад.

## Кӣ ба кӣ навишта метавонад (`MessagesService.scope`)

| Кӣ | Ба кӣ |
|---|---|
| Шеф | ба ҳамаи кормандони ширкат |
| Менеҷер | ба кормандони филиали худ ва шеф |
| Корманд | ба менеҷери филиал ва шеф |
| Ҳар кас | ба касе, ки ба ӯ навишта буд (ҷавоб) |

Саҳифаи `/messages` ду чат дорад: **WhatsApp** (ранги сабз `#1fa855`) ва **Telegram** (кабуд `#229ed9`). Паёмҳои танҳо-сайт ва зангҳо дар ҳарду намоёнанд.

## Паёмҳо

- Матн то 2000 аломат. «Ба чанд нафар» паёмро якбора то 200 қабулкунанда мефиристад.
- **Овоз** то 5 дақиқа, **видео-доира** то 60 сония, файл то 15 МБ (`VOICE_MAX_SECONDS`, `VIDEO_NOTE_MAX_SECONDS`, `MEDIA_MAX_BYTES`).
  Бадани дархост худи файл аст (`POST /api/messages/media?to=&kind=&duration=`), ва он дар `Media` (bytea) нигоҳ дошта мешавад.
- Ҳолати фиристодан ба ҳар канал: `SENT`, `DRY_RUN` (токен нест), `FAILED`, `NOT_LINKED`. ✓✓ — хонда шуд.
- Навсозӣ: фавран тавассути SSE «messages», ва барои эҳтиёт ҳар 20 сония (суҳбат) ва ҳар 30 сония (рӯйхат).

## «Дар шабака», «менависад…», «аудио сабт мекунад…»

Мисли WhatsApp/Telegram ва бо ранги ҳамон канал:

| Чӣ нишон дода мешавад | Кай |
|---|---|
| 🟢 нуқта дар аватар, «дар шабака» дар сарлавҳа | корбар сайтро кушода дорад (ақаллан як пайвасти `/api/events`) |
| «охирин бор имрӯз дар 14:30» / «дирӯз дар …» / «12 окт.» | корбар сайтро баст (`User.lastSeenAt`) |
| «менависад ⋯» | ҳамсуҳбат дар 4 сонияи охир тугма пахш кардааст |
| «аудио сабт мекунад ⋯» / «видео сабт мекунад ⋯» | сабти овоз ё видео-доира кушода аст |

Чӣ тавр кор мекунад:

```
Браузери A (менависад) ── POST /api/messages/activity {to, kind} ҳар 3 сония ──▶ API
API ── ensureCanTalk (кэш 60 сония) ── SSE «activity» {fromId, kind} ──▶ танҳо браузери B
Агар хабари нав 6 сония наояд — B «менависад»-ро худаш пинҳон мекунад; ҳангоми бас кардан A «stop» мефиристад.

Пайвасти SSE кушода шуд  ──▶ ба ҳамкорони ширкат «presence» {online: true}
Пайвасти охирин баста шуд ── 8 сония интизорӣ (нав кардани саҳифа «баромад» нест) ──▶ {online: false, lastSeenAt} + сабт дар база
```

- «Менависад» ба база намеравад. Ин танҳо хабари SSE аст, бинобар ин ҳеҷ бор надорад.
- Пайвасти SSE дар ҳар саҳифа кушода аст (зангҳо), бинобар ин «дар шабака» маънои «сайт кушода аст»-ро дорад, на танҳо «чат кушода аст».
- Миграция: `20261031090000_user_last_seen`.

## Зангҳо (WebRTC)

- Аудио ва видео **мустақим байни ду браузер** мераванд. Сервер танҳо пешниҳод/ҷавобро нигоҳ медорад (сигнал, SDP бо ҳамаи ICE-номзадҳо, non-trickle).
- STUN: Google ва Cloudflare. TURN нест, бинобар ин дар баъзе шабакаҳои мобилӣ/корпоративӣ пайваст шуда наметавонад (ниг. «Камбудиҳои маълум» дар [14](14-infra-va-bekhatari.md)).
- Занг задан ба касоне мумкин аст, ки ба онҳо паём навиштан мумкин аст. Ҳар кас занг қабул карда метавонад.
- Занги ҷавобнадода пас аз 45 сония «беҷавоб» мешавад. Натиҷа дар чат сабт мешавад («📞 Занги аудио · 2:31», «Занги беҷавоб») ва 🔔 меояд.
- Занги воридшаванда дар ҳар саҳифа пайдо мешавад (`components/calls.tsx`), ҳамчунин push-огоҳӣ ҳангоми пӯшида будани сайт.

## API

| Роҳ | Чӣ |
|---|---|
| `GET /api/messages/contacts?channel=` | рӯйхат бо охирин паём, нохондаҳо, `online`, `lastSeenAt` |
| `GET /api/messages/contacts/:id` | маълумоти корманд |
| `GET /api/messages/thread/:id?after=&channel=` | суҳбат (воридшудаҳо хонда мешаванд) |
| `POST /api/messages` | матн ба як ё чанд нафар |
| `POST /api/messages/media`, `GET /api/messages/media/:id` | овоз ва видео |
| `POST /api/messages/activity` | «менависад / сабт мекунад / stop» |
| `GET /api/messages/unread` | шумораи нохондаҳо |
| `POST /api/calls`, `GET /incoming`, `GET /:id`, `POST /:id/answer \| decline \| end` | занг |

## Тестҳо

`core/events.spec.ts`: «дар шабака» ба ҳамкорон, ширкати бегона намебинад, нав кардани саҳифа «баромад» нест, «охирин бор» пас аз 8 сония ва сабт дар база, «activity» танҳо ба қабулкунанда.
