# 03 — Фурӯш (POS) ва таърихи фурӯш

## Мақсад

Кассир, фурӯшанда, менеҷер ё шеф дар `/pos` фурӯшро дар чанд сония сабт мекунад: молро интихоб мекунад, мизоҷро аз рӯи рақам меёбад,
бонус ё коди тахфифро истифода мебарад ва бо нақд, корт ё қарз пардохт мекунад. Ҳатто бе интернет фурӯш гум намешавад.

## Ҷараёни фурӯш

```
Мол (ҷустуҷӯ / штрих-код / категория) → сабад (миқдор, касрӣ: 1,5 кг)
  → мизоҷ (ихтиёрӣ: бонус +5%)  → код тахфиф (ихтиёрӣ)  → Нақд | Корт | Қарз
  → POST /api/orders  → чек (чоп ё WhatsApp)
```

- **Нарх аз база** гирифта мешавад, на аз браузер. `OrdersService.quote()` ҷамъ, арзиши аслӣ, тахфиф ва бонусро ҳисоб мекунад.
- Тартиби тахфиф: аввал **коди тахфиф**, баъд **бонус** аз маблағи боқимонда (1 балл = 1 сомонӣ). Бонус аз баллҳои мизоҷ ва аз маблағи харид зиёд шуда наметавонад.
- Аз маблағи пардохтшуда **5%** ба мизоҷ бармегардад (`POINTS_RATE = 0.05`).
- Ҳамааш дар як транзаксия иҷро мешавад: фармоиш, бонус ва омори мизоҷ, истифодаи код (бо ҳадди `maxUses`), қарз ва кам кардани анбор.
- Пас аз фурӯш, агар мол кам монда бошад, 🔔 ба менеҷер ва шеф меравад ([04](04-mahsulot-va-anbor.md)).
- **Қарз:** шеф ва менеҷер бевосита ба қарз мефурӯшанд. Кассир «Дархост ба менеҷер»-ро мебинад, ва мол пас аз тасдиқ дода мешавад ([06](06-daftari-qarz.md)).

## POS-и офлайн

Агар интернет ё API дастрас набошад (`lib/offline-sales.ts`):

- Фурӯш дар `localStorage` бо рақами ягонаи `clientRef` нигоҳ дошта мешавад, ва дар экран «Фурӯш нигоҳ дошта шуд» пайдо мешавад.
- Ҳангоми пайдо шудани интернет ва ҳар 30 сония навбат худкор фиристода мешавад.
- `Order.clientRef @unique`: агар фурӯш ду бор расад, дубора сабт намешавад, ва сервер ҳамон фармоишро бармегардонад.
- `soldAt` — вақти воқеии фурӯш (на дар оянда ва на зиёда аз 7 рӯз пеш).
- Рӯйхати мол низ нигоҳ дошта мешавад, бинобар ин POS бе интернет кушода мешавад.
- Фурӯш ба қарз офлайн навбат намегирад, чунки тасдиқ лозим аст.

## Таърихи фурӯш

`/sales`: график ва ҷадвал аз рӯи рӯз/ҳафта/моҳ ва филиал, ҳамчунин Excel (`GET /api/orders/export` → `.xlsx`, `common/xlsx.ts` бе китобхонаи иловагӣ).
Кассир танҳо фурӯши филиали худро мебинад ва бе арзиш/фоида.

## Модел

`Order` (branchId, userId — фурӯшанда, total, totalCost, payment, customerId, discount, pointsEarned/Used, promoCode, clientRef),
`OrderItem` (productId, qty — то 3 рақам пас аз вергул, unitPrice, unitCost — нусха дар лаҳзаи фурӯш).

## API

| Роҳ | Кӣ |
|---|---|
| `GET /api/orders` (`branchId`, `from`, `to`, `page`) | фурӯшандагон (`canSell`) |
| `GET /api/orders/export` | ҳамон, Excel |
| `POST /api/orders` | шеф, менеҷер, кассир, фурӯшанда; `DEBT` аз кассир → 403 |
