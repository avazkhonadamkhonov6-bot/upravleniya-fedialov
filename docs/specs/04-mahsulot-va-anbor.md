# 04 — Маҳсулот, нархҳо ва анбор

## Маҳсулот (`Product`)

| Майдон | Маъно |
|---|---|
| `name`, `category`, `emoji`, `imageId` | ном, категория (барои POS ва бозор), иконка, акс |
| `price`, `cost` | нархи фурӯш ва арзиши аслӣ. Фоида = нарх − арзиш. Кормандон `cost`-ро намебинанд |
| `unit` | дона, кг, литр, метр… (`isFractionalUnit` — миқдори касрӣ) |
| `stock`, `lowStock` | ҷамъи анбори ҳамаи филиалҳо; ҳадди «кам монд». `stock = null` маънои «ҳисоб намешавад»-ро дорад |
| `isActive` | ғайрифаъол дар POS ва бозор нест |

- Нархҳо барои ҳамаи филиалҳо якхела ҳастанд. Танҳо шеф мол илова, таҳрир ва нест мекунад.
- Агар мол дар таърихи фурӯш бошад, он нест намешавад, балки **бойгонӣ** мешавад (`isActive = false`), то ҳисоботҳо вайрон нашаванд.
- **Акс:** браузер онро то ~100 КБ фишурда мефиристад (`lib/image.ts`). API онро дар `Media` нигоҳ медорад (то 2 МБ, `PUT /products/:id/image`)
  ва ба ҳама дар `GET /api/images/:id` медиҳад (ҷамъиятӣ, барои бозор).

## Анбори ҳар филиал (`BranchStock`)

- `products/stock.ts`: фурӯш (POS ва фармоиши онлайни «Расонида шуд») молро аз **ҳамон филиал** кам мекунад. `Product.stock` ҷамъи филиалҳо аст.
- Қабули мол ё ҳисоби дастӣ: `POST /api/products/:id/stock` (`add` ё `set` барои як филиал).
- Агар боқимонда аз `lowStock` (ё 0) поён равад, 🔔 ба шеф ва менеҷерони он филиал меравад (пас аз commit).

## API

| Роҳ | Кӣ |
|---|---|
| `GET /api/products` | `@Feature('products', 'pos')` — ҳамаи онҳое, ки мефурӯшанд ё рӯйхатро мебинанд |
| `POST`, `PATCH /:id`, `DELETE /:id`, `PUT/DELETE /:id/image`, `POST /:id/stock` | шеф |
| `GET /api/images/:id` | ҷамъиятӣ |
