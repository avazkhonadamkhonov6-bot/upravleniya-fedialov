# 08 — Ҷадвали сменаҳо, давомот ва вазифаҳо

## Ҷадвал (`/schedule`)

- Менеҷер (филиали худ) ва шеф ба кормандон смена мегузоранд: оғоз ва анҷом, то **16 соат**, бе бархӯрд бо сменаи дигари ҳамон корманд.
- «Нусхаи ҳафтаи гузашта» ҷадвалро ба ҳафтаи интихобшуда нусха мебардорад (`POST /api/shifts/copy-week`), ва сменаҳои мавҷуда такрор намешаванд.
- Корманд дар ҳамон саҳифа **«Ҷадвали ман»**-ро мебинад: сменаҳои ҳафта, вақти омад ва рафтан, соатҳо ва дер омаданҳо.
- Менеҷер ва шеф корти **«Давомоти имрӯз»**-ро мебинанд: ҳар корманд бо смена, вақти омад (барвақт/дер), вақти рафтан ва соатҳо. Корт ҳангоми ҳар «Омадам / Рафтам» худкор нав мешавад (SSE «alerts»).

## Давомот: «Омадам» / «Рафтам»

Тугма (`components/shift-button.tsx`) дар сарлавҳаи панел барои **ҳар корманд ва менеҷер** (на шеф) ва дар «Ҷадвали ман» ҳаст.
Пахш кардани он равзанаеро мекушояд, ки соати ҳозира, ҳолати смена («сари вақт», «N дақ барвақт», «N дақ дер», «Ҷадвал нест») ва майдони **паёми ихтиёрӣ** дорад.

| Чӣ | Қоида (`shifts/shifts.ts`) |
|---|---|
| Ба кадом смена | Сменаи ҷадвалшуда, ки ҳоло идома дорад ё то **8 соат** баъд сар мешавад (барвақт омадан мумкин) |
| Ҷадвал нест | Сменаи **8-соата худкор** кушода мешавад (то сменаи навбатии ҷадвалшуда, агар он зудтар бошад). Вақти омад ҳамеша сабт мешавад |
| Барвақт рафт ва баргашт | Ҳамон смена дубора кушода мешавад, вақти омади аввал мемонад |
| Ду бор «Омадам» | 400: «Шумо аллакай дар кор ҳастед» |
| `earlyMinutes` / `lateMinutes` | Чанд дақиқа пеш аз оғоз омад / дер омад (дер — аз 10 дақиқа зиёд) |
| «Рафтам» | Вақти рафтан, соатҳои кор; «N дақ барвақт рафт», агар зиёда аз 10 дақиқа пеш аз анҷоми смена бошад |
| Шеф | Смена надорад — 403 |

**Хабар ба кӣ меравад** (`tellBoss`):

```
Корманд  ──▶ менеҷери(ҳо)и филиал   (агар филиал менеҷер надошта бошад — ба шеф)
Менеҷер  ──▶ шеф(ҳо)и ширкат
```

- Бе паём: 🔔 + push, масалан «✅ Алӣ омад — 08:42 · смена 09:00–18:00 · 18 дақ барвақт» ё «👋 Алӣ рафт — 17:05 · 8 соат кор кард».
- Бо паём: як **паёми чат** аз корманд ба менеҷер («✅ Алӣ омад — 08:42 (…)\nБарвақт омадам, анборро тартиб медиҳам»). Чат худаш 🔔 мефиристад, бинобар ин хабари дугона нест, ва менеҷер метавонад дар ҳамон ҷо ҷавоб диҳад.

| Роҳ | Кӣ |
|---|---|
| `GET /api/shifts` | шеф, менеҷер (филиал); корманд — танҳо сменаҳои худ |
| `GET /api/shifts/today`, `POST`, `PATCH /:id`, `DELETE /:id`, `POST /copy-week` | шеф, менеҷер |
| `GET /api/shifts/mine`, `POST /check-in`, `POST /check-out` `{ note? }` | ҳар корманд ва менеҷер (худ) |

Контроллер: `@Feature('schedule')`. «Ҷадвал» дар `STAFF_FEATURES` барои ҳамаи вазифаҳо кушода аст.
Модел: `Shift` (userId, branchId, startsAt, endsAt, checkInAt, checkOutAt).

## Вазифаҳо (`/tasks`)

- Ҳолатҳо: `TODO` (нав) → `IN_PROGRESS` (дар раванд) → `DONE` (тайёр). Афзалият: паст, миёна, фаврӣ. Мӯҳлат.
- Шеф ба ҳар кас, менеҷер танҳо дар филиали худ вазифа медиҳад. Иҷрокунанда бояд аз ҳамон филиал бошад.
- **Корманд** танҳо вазифаҳои худро мебинад ва ҳолати онҳоро иваз мекунад. Вазифа сохтан ва нест кардан барои ӯ манъ аст.
- Ба иҷрокунанда 🔔, push ва паём дар Telegram/WhatsApp («📋 Вазифаи нав») меравад.

| Роҳ | Кӣ |
|---|---|
| `GET /api/tasks`, `PATCH /:id` | ҳама (корманд — танҳо вазифаҳои худ) |
| `POST`, `DELETE /:id` | шеф, менеҷер |

Контроллер: `@Feature('tasks')`.

## Чат ва 🔔 барои кормандон

Кормандон акнун `messages` ва `alerts` доранд: менеҷер ва шефро дар чат мебинанд (на дигар кормандонро, `MessagesService.scope`) ва 🔔-и худро мебинанд.
