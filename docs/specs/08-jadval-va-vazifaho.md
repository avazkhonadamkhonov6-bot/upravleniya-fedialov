# 08 — Ҷадвали сменаҳо, давомот ва вазифаҳо

## Ҷадвал (`/schedule`)

- Менеҷер (филиали худ) ва шеф ба кормандон смена мегузоранд: оғоз ва анҷом, то **16 соат**, бе бархӯрд бо сменаи дигари ҳамон корманд.
- «Нусхаи ҳафтаи гузашта» ҷадвалро ба ҳафтаи интихобшуда нусха мебардорад (`POST /api/shifts/copy-week`), ва сменаҳои мавҷуда такрор намешаванд.
- **Давомот:** тугмаи «Омадам» / «Рафтам» (`check-in` / `check-out`, `components/shift-button.tsx`). «Омадам» то **2 соат пеш** аз оғози смена қабул мешавад.
  ⚠️ Ҳоло тугма танҳо ба онҳое нишон дода мешавад, ки «Ҷадвал» доранд (менеҷер), ва роҳҳои `shifts` `@Feature` надоранд.
  Бинобар ин корманди `STAFF` 403 мегирад ва давомоти худро қайд карда наметавонад. Барои кушодан ба `mine`, `check-in`, `check-out` `@Feature('profile')` илова кунед ва тугмаро дар профил нишон диҳед.
- `GET /api/shifts/today` нишон медиҳад, ки кӣ омад, кӣ дер монд ва кӣ наомад. Ин дар панели асосӣ ҳам ҳаст.

| Роҳ | Кӣ |
|---|---|
| `GET /api/shifts`, `/today`, `POST`, `PATCH /:id`, `DELETE /:id`, `POST /copy-week` | шеф, менеҷер |
| `GET /api/shifts/mine`, `POST /check-in`, `POST /check-out` | шеф, менеҷер (корманди `STAFF` — 403, ниг. боло) |

Модел: `Shift` (userId, branchId, startsAt, endsAt, checkInAt, checkOutAt).

## Вазифаҳо (`/tasks`)

- Ҳолатҳо: `TODO` (нав) → `IN_PROGRESS` (дар раванд) → `DONE` (тайёр). Афзалият: паст, миёна, фаврӣ. Мӯҳлат.
- Шеф ба ҳар кас, менеҷер танҳо дар филиали худ вазифа медиҳад. Иҷрокунанда бояд аз ҳамон филиал бошад.
- Сервис корманди `STAFF`-ро танҳо ба вазифаҳои худаш маҳдуд мекунад, вале контроллер `@Feature` надорад, бинобар ин корманд ҳоло 403 мегирад. Вазифаҳо амалан барои шеф ва менеҷер ҳастанд.
- Ба иҷрокунанда 🔔, push ва паём дар Telegram/WhatsApp («📋 Вазифаи нав») меравад.

| Роҳ | Кӣ |
|---|---|
| `GET /api/tasks`, `PATCH /:id` | шеф, менеҷер (доираи худ) |
| `POST`, `DELETE /:id` | шеф, менеҷер |
