# 16 — Маош, касса, лимити қарз, QR-и давомот ва анбор

## Маош аз рӯи давомот (`/payroll`)

Шеф (ҳамаи филиалҳо ё як филиал) ва менеҷер (филиали худ) барои ҳар моҳ инҳоро мебинанд:

| Сутун | Чӣ |
|---|---|
| Маош | маоши моҳона аз профили корманд |
| Омад / ҷадвал | сменаҳои ҷадвалшуда, ки вақташон расид, ва аз онҳо чандтоаш бо «Омадам» |
| Рӯзҳо, Соат | рӯзҳое, ки «Омадам» пахш шуд (бо сменаҳои бе ҷадвал), ва соатҳои кор |
| Дер, Наомад | шумора ва дақиқаҳои дер омадан; сменаҳои ҷадвалшуда бе омадан |
| Аз рӯи давомот | **маош × омад / ҷадвал**; бе ҷадвал — маоши пурра. Ин пешниҳод аст, ва шеф онро тафтиш мекунад |

- Сменаҳои худкор («Омадам» бе ҷадвал, `Shift.isAdHoc`) ба «ҷадвал» дохил намешаванд.
- Excel: `GET /api/payroll/export?month=YYYY-MM`. Корманд давомоти моҳи худро дар корти «Маош»-и профил мебинад (`GET /api/payroll/me`).
- Файлҳо: `apps/api/src/payroll/payroll.ts` (`summarize`, `monthRange`), `apps/web/app/(app)/payroll/page.tsx`, `components/salary-card.tsx`.

## Пӯшидани касса — Z-ҳисобот («Таърихи фурӯш»)

- Барои ҳар кассир дар як рӯз: чекҳо, фурӯши **нақд / корт / қарз**, тахфифҳо, **пардохтҳои қарз**, ки ҳамон кас қабул кардааст.
- **Бояд дар касса бошад** = фурӯши нақд + пардохти нақди қарз.
- Кассир (ё менеҷер) пули ҳисобшударо менависад. **Фарқ** (камомад ё зиёдатӣ) сабт мешавад (`CashClosing`, як сабт дар як рӯз барои ҳар кас; дубора пӯшидан онро нав мекунад), ва 🔔 ба менеҷер (аз менеҷер ба шеф) меравад: «⚠️ Алӣ: фарқи касса −10 сомонӣ».
- Кассир танҳо қатори худро мебинад, менеҷер филиали худро, шеф ҳамаро. Шеф филиал надорад, бинобар ин кассаро намепӯшад.
- API: `GET /api/cash/z?date=&branchId=`, `POST /api/cash/close { countedCash, note }`. Файлҳо: `apps/api/src/cash/cash.ts`, `components/cash-closing.tsx`.

## Лимити қарз

| Лимит | Кӣ мегузорад | Қоида |
|---|---|---|
| **Ҳадди қарзи мизоҷ** (`Customer.creditLimit`) | шеф, менеҷер (формаи мизоҷ) | қарзи умумии мизоҷ аз он зиёд намешавад, ҳатто бо менеҷер ва ҳатто бо тасдиқи дархост (`assertCreditLimit`). Холӣ — бе ҳад |
| **Кассир бе тасдиқ то** (`Organization.cashierDebtLimit`) | шеф (корти ширкат дар «Профил») | агар қарзи умумии мизоҷ бо ин фурӯш аз ин маблағ зиёд нашавад, кассир бевосита мефурӯшад; вагарна «Дархост ба менеҷер». 0 — ҳамеша тасдиқ |

POS худаш нишон медиҳад, ки тасдиқ лозим аст ё не, ва ҳангоми гузаштани ҳадди мизоҷ огоҳӣ медиҳад.

## QR-и давомот

- «Ҷадвал» → **«QR барои давомот»**: QR-и филиал барои чоп. Скан кардани он `/checkin?c=<код>`-ро мекушояд, ва корманд «Омадам»-ро пахш мекунад.
- **«Омадам» танҳо бо QR** (`Branch.requireQrCheckIn`): бе QR (масалан аз хона) «Омадам» рад мешавад.
- **«Коди нав»**: QR-и кӯҳна (масалан расми он дар телефон) дигар кор намекунад. Коди нодуруст ҳамеша рад мешавад.
- API: `GET/PATCH /api/shifts/qr`, `POST /api/shifts/check-in { code }`. Файлҳо: `shifts/shifts.ts` (`verifyQr`, `attendanceQr`), `components/attendance-qr.tsx` (lazy), `app/(app)/checkin/page.tsx`.

## Таърихи анбор ва харид

- Ҳар тағйири анбор дар `StockMove` сабт мешавад: **Фурӯш**, **Фармоиши онлайн**, **Харид**, **Ҳисоби дастӣ**, **Хориҷ** (миқдори манфӣ), бо касе, ки тағйир дод, вақт ва **боқимонда пас аз тағйир**.
- Ҳангоми харид: **таъминкунанда** (бо пешниҳод аз номҳои пешина) ва **нархи харид**. Шеф ва менеҷер метавонанд нархи харидро ҳамчун арзиши аслии мол гузоранд.
- **Рӯйхати харид** (саҳифаи маҳсулот): моле, ки ба ҳадди «кам монд» расидааст, бо миқдори пешниҳодшуда (то 2 × ҳад), таъминкунанда ва нархи охирин, ҷамъи тахминӣ ва тугмаи чоп.
- API: `GET /api/products/:id/moves`, `GET /api/products/suppliers`, `GET /api/products/reorder`, `POST /api/products/:id/stock { add|set, supplier, unitCost, updateCost, note }`. Шеф, менеҷер ва анбордор (кассир — 403).
- Файлҳо: `products/stock.ts`, `products/products.ts`, `components/stock-form.tsx`, `components/reorder-list.tsx`.
