# 06 — Дафтари қарз

## Мақсад

Мизоҷ мол ба қарз мегирад. Сайт нигоҳ медорад, ки кӣ чӣ қадар қарздор аст, пардохтҳоро сабт мекунад ва ба мизоҷ дар WhatsApp/Telegram хабар ва ёдрас мефиристад.
**Кассир қарзро худаш дода наметавонад:** вай дархост мефиристад ва менеҷер тасдиқ мекунад.

## Кӣ чӣ мебинад ва чӣ мекунад

| Кӣ | Мебинад | Метавонад |
|---|---|---|
| 👑 Шеф | Ҳамаи қарзҳои ширкат, ҳамаи дархостҳо | Қарз медиҳад, тасдиқ/рад мекунад, пардохт, ёдрас |
| 🧑‍💼 Менеҷер | Мизоҷони филиали худ, дархостҳои филиал | Қарз медиҳад, **тасдиқ/рад мекунад**, пардохт, ёдрас |
| 💵 Кассир / 🛍️ Фурӯшанда | Мизоҷони филиали худ, дархостҳои худ | **Танҳо дархост** мефиристад, пардохт қабул мекунад, ёдрас |
| 🛒 Худи мизоҷ | Танҳо қарзи худ (профили бозор ва боти Telegram) | — |
| Дигарон (ошпаз, официант…) | **Ҳеҷ чиз** (403) | — |

Қоида дар код: `debtScope(user)` ва `requestScope(user)` (`apps/api/src/debts/debts.ts`).

## Ҷараёни дархост

```
Кассир: POS → «Қарз» → «Дархост ба менеҷер»        ё  Дафтари қарз → «+» → дархости қарзи дастӣ
   │  POST /api/debt-requests/sale (сабади пурра)       POST /api/debt-requests { customerId, amount }
   ▼
DebtRequest (PENDING) ── 🔔 + push ба менеҷери филиал ва шеф; SSE «debts»
   ▼
Менеҷер/шеф: «Тасдиқ»  ──▶ фурӯш ба номи кассир сабт мешавад (ё қарзи дастӣ илова мешавад) → 🔔 «молро диҳед»
            «Рад»     ──▶ ҳеҷ чиз сабт намешавад → 🔔 ба кассир
```

Қоидаҳои муҳим (`debts/debt-requests.ts`):

- Маблағи дархости фурӯш бо ҳамон `OrdersService.quote()` ҳисоб мешавад, ки фурӯши воқеӣ истифода мебарад (промо, бонус).
- Ду менеҷер як дархостро ду бор тасдиқ карда наметавонанд: аввал ҳолат бо `updateMany(... status: PENDING)` гирифта мешавад, ва фурӯш `clientRef = debt-request-<id>` дорад.
- Агар фурӯш сабт нашавад (масалан маҳсулот ғайрифаъол шуд), дархост боз `PENDING` мешавад.
- Дархости якхела (ҳамон мизоҷ ва маблағ, ҳанӯз интизор) такрор намешавад.
- Менеҷери филиали дигар дархостро намебинад (404).

## Мизоҷ қарзи худро чӣ тавр мебинад

Танҳо пас аз пайваст кардани **боти Telegram**: бот контакти худи соҳиби Telegram-ро талаб мекунад (`contact.user_id === from.id`), бинобар ин рақам тасдиқшуда аст.
Рақамеро, ки дар сайт навишта мешавад, ҳар кас навишта метавонад, ва бо он касе қарзи шахси дигарро дида метавонист.
Барои ҳамин `GET /api/shop/debts` қарзро аз рӯи `telegramChatId` меёбад, ва бе он `linked: false` бармегардад.

## Хабарҳо ба мизоҷ

- Ҳангоми қарзи нав ва пардохт: фавран дар WhatsApp-и бизнес ва Telegram.
- Ёдраси худкор: ҳар рӯз соати 10:00 (`@Cron`). Ҳар мизоҷ на зудтар аз ҳар 6 рӯз ёдрас мегирад, ва бори аввал на зудтар аз як ҳафта пас аз қарз.
- Ёдраси дастӣ: тугмаи 🔔 дар рӯйхат.

## Модел

`Customer.debt` (ҷамъ), `DebtEntry` (+ қарз / − пардохт, `orderId` барои фурӯш, `payment` барои пардохт),
`DebtRequest` (`PENDING | APPROVED | REJECTED`, `amount`, `sale` — JSON-и сабад, `requestedById`, `decidedById`, `orderId`).
Миграция: `20261030150000_debt_requests`.

## API

| Роҳ | Кӣ |
|---|---|
| `GET /api/debts/summary` | ҷамъ, қарздорон, WhatsApp, `pendingRequests` — дар доираи корбар |
| `GET /api/debts?q=` | қарздорон (доираи корбар) |
| `GET /api/debts/:customerId` | таърих |
| `POST /api/debts/:customerId/pay` | пардохт (кассир ҳам) |
| `POST /api/debts/:customerId/add` | қарзи дастӣ — шеф, менеҷер (кассир → 403) |
| `POST /api/debts/:customerId/remind` | ёдрас |
| `GET /api/debt-requests[?status=PENDING]` | дархостҳо |
| `POST /api/debt-requests`, `POST /api/debt-requests/sale` | дархост |
| `POST /api/debt-requests/:id/decide` `{ decision: APPROVE \| REJECT }` | менеҷер, шеф |
| `GET /api/shop/debts` | мизоҷи онлайн |
