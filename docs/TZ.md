# FilialHub — Топшириқи техникӣ (ТЗ)

> Ҳолат: 29.10.2026 · Нақша ва таърих: [PLAN.md](PLAN.md) · Пешрафт: [ROADMAP.md](ROADMAP.md) · Мушаххасот: [SPECS.md](SPECS.md) · Дизайн: [DESIGN.md](DESIGN.md)

## 1. Мақсад

FilialHub — системаи SaaS барои бизнесҳое, ки якчанд филиал доранд (тарабхона, мағозаи хӯрокворӣ, либос,
сантехника, техника, дорухона, маводи сохтмонӣ). Соҳиб ҳамаи филиалҳо, кормандон, фурӯш ва фоидаро дар як ҷо мебинад;
менеҷер — танҳо филиали худ; корманд — танҳо он чизе, ки барои кораш лозим аст. Мизоҷон дар бозори онлайн фармоиш медиҳанд.

## 4. Талаботи ғайрифунксионалӣ

- **Амният:** паролҳо — bcrypt; токен 12 соат; ҳар маршрут — `JwtAuthGuard` → `RolesGuard` → `StaffAccessGuard` (default deny); webhook-ҳо бо калид/имзо санҷида мешаванд.
- **Ҷудоии маълумот:** ҳеҷ корбар маълумоти бизнеси дигарро дида наметавонад (403/404), ҳатто бо дархости дастӣ ба API.
- **Суръат:** ҷавоби API (гарм) ≤ 50 мс, gzip; саҳифаҳо static prerender; графикҳо lazy.
- **Мобилӣ:** ҳамаи саҳифаҳо дар 375px бе scroll ба тараф; дар телефон менюи поён.
- **Дастрасӣ:** `prefers-reduced-motion`, `role="alert"` барои хатоҳо, контрасти рангҳо аз рӯи [DESIGN.md](DESIGN.md).
- **SEO:** саҳифаи `/` — Server Component, `metadata`, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`.

## 6. Интегратсияҳо

- **Telegram:** бот (`TELEGRAM_BOT_TOKEN`); дар Render — webhook, дар локал — polling.
- **WhatsApp:** Green-API (`GREENAPI_*`, бе Facebook) ё Meta Cloud API (`WHATSAPP_*`); пас аз 24 соат — шаблон.
- **Супер-админ:** `SUPERADMIN_EMAILS`, `SUPERADMIN_PASSWORD`, `SUPERADMIN_PHONE`.
- **Занг:** WebRTC, ихтиёрӣ сервери TURN (`NEXT_PUBLIC_TURN_*`).

Қадам ба қадам — [README.md](../README.md).
