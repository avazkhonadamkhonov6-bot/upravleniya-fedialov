# Чӣ тавр FilialHub-ро фурӯхтан

## 1. Видео 60 сония (OBS — ройгон)

Экрани компютер + овози шумо. Демо: `chef@filialhub.tj` / `demo1234`. Ҳар қадам 8–10 сония.

| Сония | Дар экран | Чӣ мегӯед |
|---|---|---|
| 0–6 | Панели асосӣ: «Имрӯз», «Дирӯз», график | «Ҳамаи филиалҳои шумо дар як экран — фурӯш ва фоида ҳар рӯз.» |
| 6–16 | Касса: 2 бургер ба сабад, «Боқимонда: 15 → 13» | «Кассир мефурӯшад — анбор худаш кам мешавад.» |
| 16–24 | Касса: аз ҳад зиёд пахш кунед → «Дар анбор танҳо 3» | «Моли набударо фурӯхтан мумкин нест. Хато нест.» |
| 24–34 | Чек → QR бо телефон скан → «Возврат» | «Мизоҷ мол баргардонд? QR-ро скан кунед — мол ба анбор, пул ба мизоҷ.» |
| 34–42 | Анбор → «Таҳлил» → «Пули хобида дар раф» | «Мебинед, кадом мол пули шуморо мехобонад.» |
| 42–50 | Telegram дар телефон: ҳисоботи шом | «Ҳар шом ҳисобот ба Telegram-и шумо.» |
| 50–60 | Саҳифаи нарх: «Ройгон» | «Ройгон оғоз кунед — filialhub… → Сабти ном.» |

Маслиҳат: бе мусиқии баланд, ҳарфҳои калон (зум 125%), охир — суроғаи сайт 3 сония дар экран.

## 2. Пилот: 1–2 мағозаи воқеӣ, 1 моҳ ройгон

1. Мағозае интихоб кунед, ки соҳибаш шуморо мешиносад (хешу табор, дӯст, ҳамсоя).
2. Шартнома дар 1 саҳифа: 1 моҳ ройгон (тарифи «Бизнес»), шумо худатон мол ва кормандонро ворид мекунед.
   Дар иваз: ҳар ҳафта 10 дақиқа фикри худро мегӯяд ва баъд иҷозат медиҳад, ки номи ӯ дар сайт бошад.
3. Рӯзи 1: молҳо (бо Excel), кормандон, Telegram-и соҳиб. Рӯзи 2–3: дар касса дар паҳлӯи кассир истед.
4. Ҳар ҳафта як рақам ҷамъ кунед: «камомади анбор пеш ва ҳозир», «вақти пӯшидани касса».
5. Охири моҳ: як ҷумла аз соҳиб + логотип + рақам («камомад 3 баробар кам шуд») → саҳифаи асосӣ.
6. Пешниҳод: «Бизнес» бо −20% барои 12 моҳ. Агар не — бепул мемонад дар «Ройгон» (1 филиал).

## 3. Нархҳо

Ҳозир: Ройгон (1 филиал, 4 корманд) → 150 → 290 → 490 → 890 сомонӣ дар моҳ.
Агар мизоҷон «гарон» гӯянд, 3 тариф беҳтар фаҳмида мешавад (масалан 0 / 99 / 249) —
танҳо `PLAN_INFO` дар `packages/shared/src/index.ts`-ро иваз кунед (пеш аз ин бо 3–5 мизоҷ гап занед).
